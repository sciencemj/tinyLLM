## 계산

- 실제 bf16 속도 배수: `89.9k / 36.6k = 2.46x`
- 1B 토큰 예상 사전학습 시간: `1,000,000,000 / 89,900 = 11,123초 = 3.09시간` (약 3시간 5분)
- 최종 peak memory: fp32 5.04GB (8GB 대비 2.96GB 여유), bf16 3.28GB (8GB 대비 4.72GB 여유)
- flash 커널: `OK`. `mask=` 제거 분기는 실행하지 않았고 `src/tinyllm/model.py`는 변경하지 않았다.
- 계획 추정치와 비교: 실제 2.46x는 2~4x 범위 안이며 범위 중간값 3x보다 0.54x(18.1%) 낮다. 예상 3.09시간은 2.3~4.6시간 범위 안이며 중간값 3.45시간보다 0.36시간(10.4%) 짧다.
- Task 7에 넘길 batch size: `24`
